# Changelog

## 1.0.0

- 提供本地知识库健康度、热力图和收件箱统计。
- 提供日记、项目日志、收件箱和灵感捕获。
- 提供持久化任务、日历和番茄钟。
- 提供主题、字号、密度、卡片排序和尺寸设置。
- 统一卡片标题字号，优化日常待办的文字、备注、圆形完成按钮和同色系优先级梯度。
- 优化功能按钮与日历日期块的主题对比度，并让笔记热力图适配不同卡片尺寸。
- 将默认欢迎语设为可编辑的“你好！Xboarder！”。
- 明确标记尚未接入的每日简报、GitHub、深度研究和 RSS 功能。
- 增加配置版本、运行时校验、目录建议和目录状态提示。
- 修复空 Vault、无效目录、任务流假数据和后台计时漂移问题。
