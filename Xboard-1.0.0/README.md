# Xboard 1.0

Xboard 1.0 是一个本地优先的知识工作台，把常用捕获入口、知识库健康度、任务、日历和专注计时集中在一个可调整的仪表盘中。

- 插件 ID：`agent-dashboard`
- 版本：`1.0.0`
- 作者：Yudan
- 最低 Obsidian 版本：`1.8.0`
- 网络请求、遥测和云同步：无

## 已实现

- 创建日记、项目日志和收件箱笔记，并在创建后打开。
- 将灵感追加到按日期保存的 Markdown 文件。
- 检查孤立笔记、0 字节空笔记、失效链接和无 YAML properties 的笔记。
- 显示知识库健康度、近一年笔记创建热力图和指定收件箱目录的文件数量。
- 将每日/每周任务持久化到用户指定的 Markdown 文件，支持优先级、DDL、完成、删除和排序。
- 在日历中查看任务日期和 DDL 紧迫程度。
- 使用专注/短休息计时器，并按日期保存已完成的专注轮数。
- 调整主题、字体、字号、布局密度、卡片顺序和卡片尺寸。
- 顶部欢迎语可以编辑，默认显示“你好！Xboarder！”。
- 在当前会话中切换或上传封面、头像和相框图片。

## 手动安装

1. 解压安装 ZIP，得到 `agent-dashboard` 文件夹。
2. 将文件夹复制到 `你的知识库/.obsidian/plugins/`。
3. 确认插件目录包含 `main.js`、`manifest.json`、`styles.css`。
4. 在 Obsidian → 设置 → 第三方插件中启用 `Xboard 1.0`。

## 首次使用

任务默认保存在 Vault 根目录的 `Xboard 待办.md`，首次添加任务时自动创建。

日记、项目日志、收件箱和灵感功能不会自动创建目录。使用这些功能前，请在 Xboard 设置中选择 Vault 中已经存在的目录。设置页会提示目录是否有效；未配置或不存在的目录不会再显示为“0 个文件”。

已有用户升级时，原来保存的非空目录和卡片配置会继续保留。

## 任务文件

Xboard 只管理任务文件中以下标记之间的内容：

```markdown
<!-- xboard:tasks:start -->
<!-- xboard:tasks:end -->
```

标记之外的内容会保留。请勿删除、复制或打乱这两个标记；检测到损坏时，Xboard 会停止写入并显示错误，避免静默覆盖任务。

## 开发

```bash
npm install
npm run dev
npm run build
npm run lint
```

生产构建生成根目录的 `main.js`。最终安装目录只需要：

```text
agent-dashboard/
  main.js
  manifest.json
  styles.css
```

## 项目结构

```text
src/
  cards/       卡片类型和注册信息
  data/        本地演示数据
  modals/      捕获、任务和知识库检查弹窗
  services/    Vault、任务和统一动作服务
  views/       仪表盘视图
  main.ts      插件入口
  settings.ts  设置、默认值和配置迁移
```

## 已知限制

- 封面、头像、相框图片和进行中的倒计时只在当前 Obsidian 会话中有效。
- 热力图使用文件创建时间；复制或同步工具可能改变该时间。
- 界面目前以中文为主。
- 为兼容 Obsidian 1.8.0，设置项暂不参与 Obsidian 1.13+ 的设置搜索。
- 尚未接入 AI、GitHub、RSS 或其他外部服务。
